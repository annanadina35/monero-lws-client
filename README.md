Monero light-wallet-server client shell — stub daemon.

## Features

- XMR path m/44'/128'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd monero-lws-client
cargo build --release
./target/release/monero-lws-client --help
```

## Tests

```bash
cargo test
```
